# Lootopia Organisation

Bienvenue dans l'organisation **Lootopia** : une suite d'applications pour la chasse au trésor, composée de plusieurs sous-projets orchestrés par le dépôt principal **lootopia-infra**.

## 🏗 Structure de l'organisation

- **lootopia-infra** : Point de départ, gestion de l'infrastructure Docker, orchestration des services, configuration globale.
- **lootopia-api** : API REST Node.js/Express, gestion des utilisateurs, authentification, documentation Swagger, connexion à PostgreSQL via Prisma.
- **lootopia-mobile** : Application mobile React Native (Expo), interface utilisateur, navigation, thèmes, connexion à l'API.
- **lootopia-web** : Application web Next.js, interface web, connexion à l'API.
